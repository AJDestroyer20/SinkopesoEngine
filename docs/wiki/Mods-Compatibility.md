# Mods Compatibility

Supported detection targets:
- Psych
- VSlice
- Kade
- Codename
- ALE-Psych

Psych-like recommended mod structure:
- `mods/<mod>/data`
- `mods/<mod>/songs`
- `mods/<mod>/scripts`
- `mods/<mod>/images`
- `mods/<mod>/stages`
- `mods/<mod>/characters`
- `mods/<mod>/weeks`

Use `ModManager.exportModTo(...)` for export scaffolding.
